# HR Analytics Project: Absenteeism Analysis & Compensation Strategy

##  Overview
This project provides a data-driven approach to understanding employee absenteeism and optimizing compensation strategies. It supports HR decision-making by identifying healthy employees for bonuses and allocating insurance budgets for non-smokers.

## 🎯 Objectives
- **Healthy Bonus Program**: Identify employees with low absenteeism and healthy lifestyle habits.
- **Non-Smoker Compensation Plan**: Allocate a $983,221 USD insurance budget to reward non-smoking employees.
- **Absenteeism Dashboard**: Visualize trends, reasons, and lifestyle factors influencing absenteeism.

## 🧠 Data Sources
- `absenteeism_at_work.csv`: Attendance records and lifestyle indicators.
- `compensation.csv`: Salary and financial data.
- `reasons.csv`: Maps numeric absence codes to descriptive reasons.

## 🔍 Methodology
- SQL joins to integrate datasets
- Filtering criteria for bonus eligibility
- Budget estimation for non-smokers
- Categorization of BMI and seasonal trends
- Dashboard creation for insights
